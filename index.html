🍳 Какая техника есть на кухне?

Отметь технику, которая у тебя есть. Рецепт попадёт в меню, только если хотя бы один его способ приготовления совпадает с выбранным тобой способом и для него хватает нужных приборов. Рецепты без заполненной связки пока не предлагаются.

🥘 Какие способы приготовления предпочитаешь?

Если не отметить ни одного способа, будут допустимы все способы, для которых у тебя есть нужная техника.

🚫 Аллергены

Аллергены и непереносимости настраиваются отдельно для каждого взрослого. Если у участника есть хотя бы одно ограничение, блюдо без проверенного состава и подтверждённых данных об аллергенах не попадёт в общий подбор.

ℹ️ Непереносимости

Справочник — ориентир по распространённым аллергенам. Это не подтверждение состава блюда и не гарантия отсутствия перекрёстного контакта.
