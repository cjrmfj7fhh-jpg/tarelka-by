### Важное следствие для модели данных

Название общего ингредиента (например, «соевый соус», «овощной бульон», «приправа для шашлыка», «сосиски») не идентифицирует продукт и его этикетку. Для подтверждения состава требуется либо:
1. конкретный бренд/вариант с актуальной этикеткой;
2. либо замена готового продукта на полностью перечисленные базовые ингредиенты с редакторски утверждённой рецептурой.

До этого продуктовые компоненты остаются непроверенными. Нельзя автоматически объявлять блюдо безопасным или снимать `needs_review`.

## Модель идентификации готовых продуктов (2026-11-26)

В `index.html` добавлены `ingredientProductCatalog`, `recipeProductComponentLinks` и функции `getIngredientProductIdentity`, `getDishProductIdentityReview`, `getProductIdentityStatus`.

Модель различает:
- `generic_type` — известен только тип (например, «соевый соус», «мясной бульон», «сосиски»), бренд/вариант неизвестен;
- `brand_variant` — рецепт называет конкретную марку и вариант;
- `labelStatus` отдельно описывает качество источника: этикетка/страница производителя, только категория производителя или продукт не идентифицирован.

Для компонентов хранятся категория, каноническое имя, марка/вариант (если известны), рынок источника, статус этикетки, раздельные списки `contains`, `mayContain`, `unknown`, область применимости доказательства, ссылка и дата проверки. Состав примера одного бренда не распространяется на другие марки.

Привязки сделаны для составных продуктов в рецептах ID 5, 8, 11, 41, 42, 44, 48, 81, 83, 111, 114 и 116: соевый соус, смеси овощей, бульоны, сосиски, колбасы, ветчина, майонез и приправы. В карточках меню добавлена короткая пометка: неизвестная марка требует проверки упаковки; для названного бренда — сверки актуальной упаковки.

Категория `tree_nuts` включает общие названия и распространённые виды/производные: орехи, ореховую смесь/пасту/муку, грецкий орех, миндаль и миндальную муку, фундук, кешью, фисташки, пекан, бразильский орех, макадамию и кедровые орехи.

Арахис остаётся отдельной категорией `peanuts`. Кокос не включён в `tree_nuts`, поскольку его автоматическое объединение с древесными орехами может давать неверную классификацию.

## Что требуется до статуса verified

- Сверить рецептуру с конкретным источником и подтвердить полноту состава.
- Проверить состав бульонов, соусов, приправ, смесей специй, колбас, сосисок, ветчины, маринадов и готовых паст по конкретным этикеткам.
- Разметить каждый аллерген отдельно по подтверждённым ингредиентам.
- Проверить следы и перекрёстный контакт, провести редакторскую контрольную готовку и взвесить выход.
- Для рецептов-кандидатов без количеств сначала зафиксировать точную рецептуру и граммовки.

До выполнения этих шагов приложение не должно называть рецепты безопасными для человека с аллергией. Отсутствие подходящего рецепта предпочтительнее небезопасной рекомендации.

- Адаптация создаёт персональную копию блюда и удаляет аллергенный ингредиент из её состава; исходный рецепт каталога не изменяется. Замены попадают в список покупок, если они заданы в рецепте.
- Для персональных завтраков, ужинов и индивидуального fallback общего обеда адаптированное блюдо сопровождается заметным предупреждением. Если общее второе блюдо не подходит всем участникам, генератор пробует подобрать второе отдельно каждому взрослому.
- Неизвестный состав, неподтверждённые готовые продукты и непроверенные следы аллергенов не считаются безопасными. Если для выбранной аллергии нет точного правила адаптации, рецепт по-прежнему блокируется. Непереносимости автоматически не адаптируются.
- В карточке прямо указано: адаптация не подтверждает безопасность; необходимо проверить полный состав, маркировку «может содержать» и риск перекрёстного контакта.
- Ни один рецепт не переведён в `verified`. Все существующие статусы `needs_review` сохранены.
- Целевые проверки: адаптация удаляет грецкие орехи из персональной копии ID 93; добавляет оливковое масло и лимонный сок; адаптирует гранолу ID 33; неизвестный непроверенный рецепт без явного правила остаётся заблокирован; исходная запись каталога не меняется.
- Проверка синтаксиса обоих inline-script блоков: PASS.
- Ограничение пилота: адаптации описаны только для трёх конкретных рецептов с явно записанными орехами. Это не универсальная замена аллергенов; расширение требует отдельной редакторской проверки каждой пары «рецепт — аллерген — замена».
