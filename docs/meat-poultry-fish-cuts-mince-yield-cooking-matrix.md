# Мясо, птица и рыба: виды, части, жирность, выход, замены и приготовление

Дата: 2026-11-26  
Статус: `editorial_draft`. Документ задаёт правила каталога белковых продуктов и рецептурного планировщика. Значения выхода и пищевой ценности — стартовые диапазоны/оценки; перед активацией нужны этикетки конкретных товаров и контрольные приготовления. Не считать название категории достаточным описанием продукта: часть туши, наличие кожи/кости, жирность, состав фарша и состояние массы должны быть явными.

## 1. Цели и основные принципы

Планировщик должен:
- различать вид животного, часть, форму продукта, жирность, наличие кожи/кости и степень обработки;
- не смешивать филе, бедро, голень, фарш из разных частей и готовые полуфабрикаты;
- учитывать сырой вес, съедобную подготовленную массу и готовый выход;
- рассчитывать КБЖУ по конкретной части и составу, а не по общему ярлыку «курица» или «говядина»;
- предлагать замены только после проверки вкусовой роли, жирности, времени приготовления, ограничений и КБЖУ;
- исключать нелюбимые ингредиенты на уровне состава, включая скрытые компоненты фарша, маринадов и полуфабрикатов;
- учитывать семейные порции и индивидуальные добавки к общей основе блюда;
- не выдавать справочные оценки за точные значения конкретного магазинного продукта.

## 2. Состояния продукта и единицы массы

Для каждого ингредиента хранить:
- `as_purchased_g` — масса покупки с упаковкой/впитывающей подложкой исключённой, но с костями/кожей, если они продаются вместе с продуктом;
- `raw_edible_g` — сырая съедобная масса после удаления несъедобных частей;
- `prepared_raw_g` — подготовленная масса после зачистки, нарезки и удаления костей/кожи по рецепту;
- `cooked_g` — готовая масса после приготовления;
- `drained_g` — масса после слива жидкости/рассола/жира, если это часть технологии;
- `frozen_net_g` — масса замороженного продукта без упаковки; глазурь/лёд фиксировать отдельно;
- `fat_percent` — жирность только если она указана на этикетке или подтверждена источником;
- `bone_in`, `skin_on`, `mince_cut`, `mince_composition` — явные характеристики продукта.

Расчёт покупки:

`purchase_mass = required_edible_raw_mass / edible_yield_fraction`

Расчёт порции должен опираться на фактическую готовую массу партии и число/массу порций. Не применять один коэффициент потерь одновременно к сырой съедобной массе и к готовому выходу.

## 3. Птица: каталог частей и особенности

| Продукт | Что должно быть указано | Технологическая роль | Особенности КБЖУ |
|---|---|---|---|
| Куриное филе грудки | без кожи/с кожей, целое/нарезанное | быстрое жарение, запекание, пар, тушение | обычно постное; легко пересушить |
| Куриное бедро без кости | кожа отдельно/включена, сырой вес | запекание, тушение, фарш, аэрогриль | обычно сочнее и жирнее грудки |
| Куриное бедро на кости | кость и кожа, масса покупки | запекание, тушение, бульон | покупная масса не равна съедобной |
| Голень | кожа, кость, масса | запекание, тушение, аэрогриль | учитывать кость и кожу |
| Крылья | целые/разделанные, кожа | запекание, аэрогриль | высокая доля костей и кожи |
| Целая курица | потрошёная/непотрошёная, масса, кожа | запекание, разделка, бульон | выход зависит от разделки и костей |
| Индейка: филе грудки | без кожи/с кожей | запекание, тушение, котлеты | постное, требует контроля сочности |
| Индейка: бедро | без кости/на кости, кожа | тушение, запекание, фарш | обычно более сочное и жирное, чем грудка |
| Индейка: голень/крыло | кость, кожа | длительное тушение/запекание | невысокий съедобный выход |

### Правила выбора птицы
1. Если в рецепте написано «курица», это недостаточно для точного расчёта. В активной карточке указывать конкретную часть или разрешённые варианты.
2. Не заменять куриную грудку бедром без пересчёта КБЖУ и времени приготовления.
3. Для грудки использовать щадящие способы: маринад, соус, запекание под крышкой/в форме, короткое обжаривание с доведением до готовности.
4. Бедро подходит для сочных котлет, тефтелей, тушения и рагу; жирность зависит от кожи и зачистки.
5. Если рецепт предполагает фарш, отдельно хранить происхождение фарша и состав, не подменять филе готовым магазинным фаршем.
6. Для костных частей планировать массу покупки выше требуемой съедобной массы и учитывать фактический выход после разделки.

## 4. Мясо: части и кулинарные роли

| Вид и часть | Подходящие блюда/методы | Важные параметры |
|---|---|---|
| Говядина: вырезка/тонкий край | быстрое обжаривание, запекание целым куском | цена выше; не требует долгого тушения |
| Говядина: лопатка | тушение, гуляш, фарш | соединительная ткань требует времени |
| Говядина: шея | фарш, тушение | жирность зависит от зачистки |
| Говядина: грудинка | длительное тушение, бульон | жир и соединительная ткань |
| Говядина: голяшка | супы, длительное тушение | кость/сухожилия; учитывать выход |
| Свинина: вырезка/корейка | запекание, быстрое приготовление | постные варианты легко пересушить |
| Свинина: лопатка | тушение, фарш, запекание | универсальна; жирность меняется по зачистке |
| Свинина: шея | запекание, тушение, фарш | более жирная и сочная |
| Свинина: грудинка | запекание/тушение небольшими порциями | жирность высокая, порцию учитывать особенно внимательно |
| Телятина | тушение, запекание, котлеты | указывать конкретную часть |
| Баранина: лопатка/нога | тушение, запекание | выраженный вкус и переменная жирность |

### Общие правила для мяса
- Указывать вид, часть, наличие кости и видимый жир.
- Не использовать один нутриентный профиль для всех частей одного животного.
- Для тушения выбирать части с соединительной тканью; для быстрой жарки — подходящие нежные части.
- Для постных частей предусматривать влагосберегающую технологию, но не компенсировать сухость произвольным количеством масла без отражения в КБЖУ.
- При покупке на кости рассчитывать съедобный выход отдельно.
- Жир, удалённый при зачистке, не включать в нутриенты подготовленной порции; если жир остаётся в блюде/соусе, учитывать его в рецепте.

## 5. Рыба и морепродукты

| Продукт | Форма/параметры | Типичное применение | Что влияет на расчёт |
|---|---|---|---|
| Минтай | филе/тушка, кожа/кости | запекание, пар, котлеты, суп | филе и тушка имеют разный выход |
| Хек | филе/тушка | запекание, тушение, суп | кости/кожа и глазурь |
| Треска | филе/порционные куски | запекание, пар, тушение | постная рыба, быстро пересыхает |
| Судак | филе/тушка | запекание, котлеты | учитывать кости и цену |
| Лосось/форель | филе/стейк, кожа | запекание, сковорода | жирнее белой рыбы; замена меняет КБЖУ заметно |
| Скумбрия | целая/филе | запекание, гриль | жирная рыба, выраженный вкус |
| Сельдь | свежая/солёная/маринованная | холодные блюда | соль и рассол меняют состав |
| Тунец консервированный | в собственном соку/масле, масса после слива | салаты, паста, начинка | считать drained weight и масло/сок отдельно |
| Креветки | очищенные/неочищенные, глазурь | быстрое приготовление | масса панциря и глазури |
| Рыбный фарш | вид рыбы и состав | котлеты, тефтели | не использовать без известного состава |

### Правила рыбного каталога
1. Белая и жирная рыба — не взаимозаменяемы по КБЖУ.
2. Замена минтая на лосося требует пересчёта жиров и калорий, даже если масса порции та же.
3. Для замороженного филе учитывать глазурь и массу нетто по маркировке.
4. Для консервов использовать массу после слива, если рецепт не использует жидкость.
5. Указывать наличие костей и кожи; для детального расчёта тушки требуется съедобный выход после разделки.
6. Не предлагать рыбу с неизвестным составом фарша при строгом исключении конкретного вида.
7. Солёную/копчёную/маринованную рыбу считать отдельной формой с отдельными данными по соли и нутриентам.

## 6. Ориентировочный съедобный выход

Диапазоны — стартовые планировочные ориентиры, не нормативы для каждого магазина и размера продукта. Проверять по фактической партии.

| Продукт | Съедобная сырая масса от массы покупки | Комментарий |
|---|---:|---|
| Куриное филе без кожи/кости | 95–100% | возможна зачистка плёнок и жира |
| Куриное бедро без кости/кожи | 90–98% | зависит от зачистки |
| Бедро на кости с кожей | 60–75% | часть массы — кость и кожа |
| Голень на кости | 55–70% | кость и кожа |
| Крылья | 45–60% | кости и кожа |
| Целая потрошёная курица | 55–70% | зависит от разделки и использования кожи/крыльев |
| Индюшиное филе | 95–100% | при минимальной зачистке |
| Индюшиное бедро на кости | 60–75% | зависит от кости и кожи |
| Говяжье филе/мякоть без кости | 90–98% | зачистка плёнок и жира |
| Говядина на кости | 55–75% | часть массы — кость |
| Свинина без кости | 90–98% | зависит от видимого жира и зачистки |
| Свинина на кости | 65–80% | часть массы — кость |
| Рыбное филе без кожи/костей | 95–100% | учитывать обрезь и глазурь |
| Рыба филе с кожей/костями | 75–95% | зависит от продукта |
| Целая рыба | 40–60% | потрошение, голова, кости и кожа |
| Креветки неочищенные | 40–60% | панцирь/голова; вид и размер сильно влияют |

Не показывать пользователю псевдоточность: если коэффициент не проверен, отображать диапазон или округлённую оценку.

## 7. Фарш: происхождение, жирность и состав

Фарш — самостоятельный продукт, не эквивалентный мясу, название которого указано крупно на упаковке.

Обязательные поля:
- вид животного;
- часть/сырьё, если указано;
- состав в порядке маркировки;
- доля мяса/жира, если известна;
- добавленная вода, кожа, шпик, соль, специи, крахмал и другие добавки;
- пищевая ценность с этикетки;
- дата/источник проверки;
- состояние: охлаждённый или замороженный.

### Типы фарша для рецептурного каталога
- куриный из грудки/филе — постный, требует аккуратного добавления влаги;
- куриный из бедра — более сочный, жирность зависит от кожи и зачистки;
- индюшиный из грудки — постный, подходит для тефтелей и котлет с влагосодержащими добавками;
- индюшиный из бедра — сочнее и обычно жирнее грудки;
- говяжий — фиксировать жирность по маркировке/этикетке, не угадывать по цвету;
- свиной — фиксировать жирность и часть, если известны;
- смешанный говяжье-свиной — хранить доли компонентов, если указаны;
- магазинный «домашний»/«особый» — использовать только по фактическому составу и КБЖУ с этикетки;
- рыбный — обязательно хранить вид рыбы и дополнительные ингредиенты.

### Ключевое правило
Если упаковка сообщает «куриный фарш», но состав включает филе и шпик, продукт не должен получать КБЖУ чистого куриного филе. Если часть/жирность неизвестны, использовать этикетку как основной источник; не выводить жирность из маркетингового названия.

## 8. Жирность и варианты для одного рецепта

Один рецепт может иметь несколько технологических вариантов:
- постный: филе/постный фарш, минимум добавленного масла, дополнительная влага из овощей/соуса;
- стандартный: бедро или фарш средней жирности;
- более сочный: часть с большим количеством собственного жира, но с пересчитанными КБЖУ;
- бюджетный: доступная часть для тушения или фарш по фактической этикетке;
- облегчённый: уменьшение жирных добавок, но без обещания одинаковой текстуры.

Не задавать универсальные значения жирности «постный/средний/жирный» без источника. Лучше хранить точное значение этикетки и использовать категории только для фильтра/подсказки.

## 9. Замены между видами и частями

| Исходный продукт | Возможная замена | Что обязательно пересчитать |
|---|---|---|
| Куриная грудка | индюшиная грудка | время/толщина куска, КБЖУ |
| Куриная грудка | куриное бедро без кости | жирность, время, съедобный выход |
| Куриное бедро | индюшиное бедро | время и фактическая жирность |
| Куриный фарш из бедра | фарш из грудки | сочность, влага/связующие, КБЖУ |
| Говяжий фарш | смешанный говяжье-свиной | жирность, КБЖУ, вкус |
| Говядина для тушения | свиная лопатка | вкус, время, жирность |
| Минтай | хек/треска | выход, влажность, время |
| Минтай | лосось/форель | значительное изменение жира и калорий |
| Рыбное филе | рыбный фарш | текстура, состав, связующие и выход |
| Свежая рыба | замороженное филе | глазурь, масса нетто, выделение жидкости |

Запрещено автоматически:
- заменять любой вид мяса любым другим без проверки диеты, вкуса и времени;
- заменять постное мясо жирным без пересчёта;
- заменять рыбу фаршем с неизвестным составом;
- считать мясо на кости эквивалентным филе по массе;
- подменять конкретный нелюбимый продукт другим названием того же ингредиента.

## 10. Способы приготовления и адаптация под оборудование

| Метод | Подходящие продукты | Контроль |
|---|---|---|
| Сковорода | тонкие куски, фарш, котлеты, рыба | не переполнять, контролировать толщину и прожарку |
| Духовка | целая птица, части на кости, запеканки, рыба | учитывать размер, форму, наличие крышки/фольги |
| Аэрогриль | порционные куски, котлеты, крылья, овощи с мясом | не перегружать корзину; переворачивать по необходимости |
| Мультиварка | тушёное мясо, рагу, тефтели, бульон | режимы зависят от модели и объёма |
| Кастрюля | суп, варка, тушение | время зависит от части и размера |
| Пароварка | рыба, птица небольшими кусками, тефтели | контролировать толщину и полную готовность |
| Микроволновка | разогрев готовых блюд, отдельные быстрые приготовления | равномерно распределять, перемешивать/выдерживать по инструкции |

### Технологические правила
- Для фарша важны связность и удержание влаги: яйцо, крупа, хлеб, овощи и молочные компоненты добавляются только если они предусмотрены рецептом и допустимы по ограничениям.
- При смене сковороды на духовку/аэрогриль пересматривать температуру, время, размер порции и количество масла.
- Для костных частей проверять готовность у кости, а не только по цвету поверхности.
- Не считать время готовки универсальным: указывать диапазон и критерий готовности.
- Масло, маринад, панировку и соус считать отдельными ингредиентами.

## 11. Безопасность приготовления и хранения

- Сырое мясо, птицу и рыбу хранить отдельно от готовых продуктов и овощей, использовать отдельные доски/инвентарь либо тщательно мыть их между операциями.
- Размораживать в холодильнике или безопасным способом по инструкции; не оставлять надолго при комнатной температуре.
- Не мыть сырую птицу под краном: брызги могут распространять загрязнение по кухне.
- Для оценки готовности предпочтителен пищевой термометр в самой толстой части, избегая кости.
- Как консервативные домашние ориентиры для внутренней температуры: птица — 74°C; фарш из мяса — 71°C; рыба — около 63°C. Для целых кусков мяса и специальных продуктов применять рекомендации пищевой безопасности для конкретного вида и способа; цвет сам по себе не является надёжным критерием.
- После приготовления не оставлять скоропортящиеся блюда надолго при комнатной температуре; быстро охлаждать, убирать в холодильник и соблюдать сроки для конкретного блюда.
- Сырые маринады, контактировавшие с мясом/рыбой, не использовать как готовый соус без полноценной термической обработки.
- Для фарша и рубленых изделий риск выше, чем для цельного куска: готовить до безопасной температуры по всему объёму.
- При сомнении в запахе, хранении, температуре или целостности упаковки продукт не использовать.

## 12. КБЖУ и источники данных

Приоритет источников:
1. Этикетка конкретного продукта, если она относится к той же форме и составу.
2. Данные производителя для точного SKU.
3. Надёжная таблица пищевой ценности для конкретной части и состояния.
4. Усреднённое справочное значение — только если более точных данных нет.

Правила:
- различать сырой и приготовленный продукт;
- учитывать кожу, кость, видимый жир, глазурь, рассол и масло;
- для фарша брать состав и значения с этикетки;
- не смешивать показатели на 100 г сырого продукта с весом готовой порции без пересчёта;
- при тушении учитывать жир/сок, который остаётся в блюде, и то, что сливается;
- не выводить углеводы как ноль, если они неизвестны: хранить `null`/«нет данных»;
- сохранять дату и источник данных, чтобы можно было обновлять каталог;
- округлять результат с учётом качества исходных данных.

## 13. Связь с предпочтениями, аллергиями и семейным меню

- Исключение «курица» блокирует грудку, бедро, голень, крылья, куриный фарш, куриный бульон и составные продукты с курицей.
- Исключение конкретной части (например, куриная грудка) не должно автоматически исключать индейку, если пользователь не исключил птицу целиком.
- Исключение «рыба» блокирует все виды рыбы и рыбные продукты; исключение минтая — только минтай и продукты, где он есть в составе, если правило пользователя не шире.
- Проверять ингредиенты в маринадах, соусах, готовых котлетах, фарше и полуфабрикатах.
- Аллергены имеют приоритет над любимыми продуктами и допустимыми заменами.
- При смешанных предпочтениях домохозяйства строить общую безопасную основу (например, овощи/крупа/соус), а белковую часть добавлять отдельно для каждого профиля.
- Порции рассчитывать только для людей, которые едят конкретный приём пищи.
- Не создавать отдельные несовместимые меню, если возможно собрать общее блюдо с индивидуальной добавкой.

## 14. Модель данных

Рекомендуемые поля:
- `ingredient_id`, `canonical_name`, `aliases`, `animal_species`, `cut`, `product_form`;
- `bone_in`, `skin_on`, `visible_fat_trim`, `fat_percent`, `mince_cut`, `mince_composition`;
- `fresh_frozen_canned_smoked_salted`, `glaze_fraction`, `drained_weight_g`;
- `purchase_unit`, `purchase_mass_g`, `raw_edible_yield_min`, `raw_edible_yield_max`;
- `cooked_yield_factor`, `yield_source`, `yield_checked_at`;
- `nutrition_basis`, `kcal_100g`, `protein_100g`, `fat_100g`, `carbs_100g`, `nutrition_source`, `nutrition_checked_at`;
- `allergen_tags`, `diet_tags`, `dislike_tags`, `cross_contact_notes`;
- `compatible_methods`, `functional_role`, `substitution_group`;
- `storage_guidance`, `price_source`, `price_observed_at`, `price_confidence`.

Не хранить «курица» или «рыба» как единственный ключ для расчёта КБЖУ, если известны часть/вид и состояние. Алиасы должны нормализовать формы названия, но не стирать различия частей и состава.

## 15. Контрольные рецепты для валидации

Минимальный набор для контрольной готовки и автоматических тестов:
1. Куриная грудка, запечённая без кожи.
2. Куриное бедро без кости в аэрогриле.
3. Куриные котлеты из филе.
4. Котлеты из бедренного куриного фарша.
5. Индюшиные тефтели в соусе.
6. Говяжьи котлеты с указанной жирностью фарша.
7. Тушёная говядина из лопатки.
8. Свинина из лопатки с овощами.
9. Минтай в духовке.
10. Лосось с овощным гарниром.
11. Рыбные котлеты из филе с точно указанным видом рыбы.
12. Консервированный тунец с учётом массы после слива.

Для каждого теста фиксировать:
- массу покупки и подготовленную съедобную массу;
- точный SKU/этикетку и состав;
- массу каждого ингредиента;
- оборудование, режим, температуру, время и толщину куска;
- готовый выход и число порций;
- КБЖУ партии и порции;
- потери/остатки и фактически использованное масло/соус;
- результат замены и ожидаемое изменение КБЖУ.

## 16. Проверки планировщика

| Входные условия | Ожидаемое поведение |
|---|---|
| Пользователь исключил курицу | Ни один рецепт/соус/фарш/бульон с курицей не появляется |
| Пользователь исключил только грудку | Бедро может остаться допустимым, если нет более широкого запрета |
| В рецепте указано 500 г мякоти, покупается мясо на кости | Список покупок увеличивает массу по выходу |
| Куриный фарш содержит шпик | КБЖУ берётся с этикетки/состава, не из профиля грудки |
| Фарш не имеет раскрытого состава | Не назначать точную жирность; пометить неопределённость |
| Минтай заменён лососем | Пересчитать КБЖУ и явно показать изменение |
| Консервированный тунец в масле | Использовать drained weight и учитывать масло по фактическому рецепту |
| Два члена семьи едят мясную добавку, один — вегетарианскую | Общая гарнирная/овощная основа, отдельные белковые компоненты |
| Замороженное филе покрыто глазурью | Рассчитать массу нетто по маркировке |
| Источник не сообщает углеводы | Не подставлять ноль без основания |

## 17. Критерии готовности

- [ ] Части птицы, мяса и рыбы разведены в каталоге.
- [ ] Фарш имеет отдельную модель состава и источника КБЖУ.
- [ ] Масса покупки не смешивается со съедобной и готовой массой.
- [ ] Для костных продуктов задан предварительный диапазон выхода.
- [ ] Замены меняют КБЖУ, время и технологию там, где это необходимо.
- [ ] Нелюбимый продукт исключается во всех формах и вложенных составах.
- [ ] Аллергены и диетические ограничения имеют приоритет.
- [ ] Есть контрольные рецепты для грудки, бедра, фарша, тушения и разных видов рыбы.
- [ ] Редакторские оценки не помечены как проверенные контрольной готовкой.

## 18. Ограничения

Диапазоны съедобного выхода и пищевые значения предварительны и зависят от части, производителя, зачистки, состава, заморозки и технологии. Температурные ориентиры — консервативные домашние ориентиры, не замена официальным требованиям и маркировке конкретного продукта. Перед переводом карточек в активный каталог необходимы проверка упаковок, повторные взвешивания и контрольные приготовления. Этот этап меняет только документацию; runtime и UI не затрагиваются.
